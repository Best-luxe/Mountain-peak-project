# Sales Analysis Project

## Description
This project analyzes sales data to understand customer behavior, store performance, employee performance, and product sales trends using SQL.

## Tools Used
- PostgreSQL
- pgAdmin
- SQL

## Key Findings
- Identified top-performing stores based on revenue.
- Analyzed product performance and customer purchasing patterns.
- Compared employee sales performance.
